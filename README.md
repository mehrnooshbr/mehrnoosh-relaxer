# mehrnoosh-relaxer
 🌿 Mehrnoosh Relaxer

*A little space to pause, breathe, and reconnect with yourself.*

 About the Project

**Mehrnoosh Relaxer** is a calming breathing exercise web application designed to offer a simple, peaceful moment in the middle of a busy day.

Featuring a soothing landscape background and gentle circular animations, the application guides users through a breathing exercise with German instructions, including *„Einatmen“* (breathe in) and *„Ausatmen“* (breathe out).

The goal is to create a relaxing visual experience that encourages users to slow down, focus on their breathing, and take a moment for themselves.

 ✨ Features

-  A peaceful landscape background
-  Animated circles inspired by the natural rhythm of breathing
- 🇩🇪 German breathing instructions
-  A calming, visually focused interface

🛠️ Technologies

- HTML
- CSS

🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Follow the on-screen breathing instructions and enjoy a moment of calm.

No additional software or server setup is required for the standard static version.

### 🇩🇪 Über das Projekt

**Mehrnoosh Relaxer** ist eine kleine Webanwendung für Atemübungen. Mit einer beruhigenden Landschaft und sanften Kreisanimationen unterstützt sie die Nutzer dabei, sich auf ihre Atmung zu konzentrieren. Die Anweisungen „Einatmen“ und „Ausatmen“ begleiten die Atemübung und schaffen einen ruhigen Moment im Alltag.

Das Projekt wurde mit HTML, CSS und JavaScript entwickelt.
